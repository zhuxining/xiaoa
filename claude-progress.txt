## 项目概述

小A 是一个面向非 Coding 群体的 Agent 工作站。
技术栈: Electron Forge + React 19 | TailwindCSS 4 + shadcn/ui | TanStack Router + Query | oRPC | pi-agent-core + pi-ai

## 开发笔记

### 环境要求
- Node.js 18+
- Bun (包管理器)
- Electron Forge

### 常用命令
```bash
bun run start        # 启动开发模式
bun run test         # 运行单元测试
bun run test:e2e     # 运行端到端测试
bun run check-types  # 类型检查
bun run check        # 代码质量检查
```

### 架构要点
- IPC 通信使用 oRPC (非传统 ipcMain/ipcRenderer)
- 状态管理使用 TanStack Query (无全局状态库)
- Agent 运行在 Main 进程，Renderer 通过 oRPC 交互
- 工具定义使用 TypeBox (非 Zod)
